## What this is

Personal blog of Nicolas LHOMME (https://blog.lhomme.xyz), built with Jekyll using the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme (gem-based, currently `~> 7.2`). Content is in French (`lang: fr-FR`, `timezone: Europe/Paris`). Deployed to GitHub Pages from `main` via `.github/workflows/pages-deploy.yml`.

## Common commands

```bash
# Local dev server with livereload (binds 127.0.0.1 by default)
bash tools/run.sh
bash tools/run.sh -H 0.0.0.0      # expose on LAN
bash tools/run.sh -p              # JEKYLL_ENV=production

# Full production build + htmlproofer link check (mirrors CI)
bash tools/test.sh

# Direct equivalents
bundle exec jekyll s -l
JEKYLL_ENV=production bundle exec jekyll b -d _site
bundle exec htmlproofer _site --disable-external \
  --ignore-urls "/^http:\/\/127.0.0.1/,/^http:\/\/0.0.0.0/,/^http:\/\/localhost/"
```

Ruby 3.3 is used in CI; install deps with `bundle install`.

## Architecture notes

- **Theme is a gem, not vendored.** Layouts, includes, and sass live inside the `jekyll-theme-chirpy` gem (run `bundle info --path jekyll-theme-chirpy` to inspect). Only `_config.yml`, `_plugins/`, `_tabs/`, `_data/`, `assets/`, and `index.html` are in this repo per Chirpy starter conventions. To override theme files, copy them locally first.
- **Posts** live in `_posts/` as `YYYY-MM-DD-slug.md` with Chirpy front matter (`title`, `date`, `categories`, `tags`). Permalinks are forced to `/posts/:title/` by `_config.yml` defaults — changing that would break every existing inbound link.
- **`_plugins/posts-lastmod-hook.rb`** sets `last_modified_at` on each post from `git log` if the file has more than one commit. This means CI needs `fetch-depth: 0` (already set) and that local builds without full git history will skip the lastmod.
- **`_tabs/`** are Chirpy "tab" collection pages (about, archives, categories, tags) rendered with `layout: page` and `permalink: /:title/`.
- **jekyll-archives** is enabled for both categories and tags with permalinks `/categories/:name/` and `/tags/:name/`.
- **`robots.txt`** is custom (not generated by the theme).

## CI/deploy specifics

`pages-deploy.yml` triggers on push to `main` (or `master`), ignoring `.gitignore`, `README.md`, `LICENSE`. It runs `jekyll build` then `htmlproofer` with external link checks disabled — broken external URLs will not fail CI, but broken internal links will. Deployment is via the official `actions/deploy-pages@v4` flow, not a `gh-pages` branch.
